WINE OLEAUT32 STOP TIME FIX

LOCATION: dlls/oleaut32/variant.c
FUNCTION: VarUdateFromDate

PROBLEM:
The rounding logic in VarUdateFromDate causes fractional seconds > 0.5 to round up,
leading to overflow into year 10000 when processing dates like 9999-12-31T23:59:59.999.

CURRENT CODE (around lines 1459-1483):
if (timePart > 0.5)
{
  /* Round the milliseconds, adjusting the time/date forward if needed */
  if (lpUdate->st.wSecond < 59)
    lpUdate->st.wSecond++;
  else
  {
    lpUdate->st.wSecond = 0;
    if (lpUdate->st.wMinute < 59)
      lpUdate->st.wMinute++;
    else
    {
      lpUdate->st.wMinute = 0;
      if (lpUdate->st.wHour < 23)
        lpUdate->st.wHour++;
      else
      {
        lpUdate->st.wHour = 0;
        /* Roll over a whole day */
        if (++lpUdate->st.wDay > 28)
          VARIANT_RollUdate(lpUdate);
      }
    }
  }
}

FIXED CODE:
if (timePart > 0.5)
{
  /* Prevent StopTime overflow into year 10000 */
  int proposed_second = lpUdate->st.wSecond + 1;

  /* If rounding would cause second overflow */
  if (proposed_second > 59)
  {
    /* Check if this would cause date overflow that leads to year 10000 */
    if (lpUdate->st.wHour == 23 && lpUdate->st.wMinute == 59 && lpUdate->st.wSecond == 59)
    {
      /* Would overflow to next day - prevent by truncating instead of rounding */
      lpUdate->st.wSecond = 59;
      lpUdate->st.wMinute = 59;
      lpUdate->st.wHour = 23;
    }
    else
    {
      /* Apply normal overflow handling */
      if (lpUdate->st.wMinute < 59)
      {
        lpUdate->st.wSecond = 59;
        lpUdate->st.wMinute++;
      }
      else
      {
        lpUdate->st.wSecond = 59;
        lpUdate->st.wMinute = 0;
        lpUdate->st.wHour++;
      }
    }
  }
  else
  {
    /* Normal rounding case */
    lpUdate->st.wSecond++;
  }
}

2. Navigate to dlls/oleaut32/variant.c
3. Locate the VarUdateFromDate function
4. Replace the rounding logic with the fixed version above
5. Rebuild Wine: make clean && make
6. Install patched Wine
7. Test Power BI Desktop

This fix prevents the StopTime overflow that was causing Power BI Desktop to crash.
